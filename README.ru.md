# mercurius-command-policy

[English](README.md) | **Русский**

Классификация команд по опасности и политика исполнения: чтение — только если доказано, список «никогда», матрица «роль × группа серверов», разовые разрешения, квоты и журнал решений. Одна политика для локальной песочницы и для SSH.

Часть проекта [Меркурий (Mercurius)](https://github.com/opencck/mercurius) — автономного персонального агента. Пакет не зависит от приложения Меркурия и может использоваться отдельно.

**Статус:** запланирован, кода пока нет.

**Стек:** PHP 8.2+.
